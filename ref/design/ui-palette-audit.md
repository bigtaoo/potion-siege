## 2. 色板：令牌与硬编码

已有三组令牌：
- `COLORS`（ui.ts）：战斗深蓝底
- `P`（kit/palette.ts）：菜单木头、黄铜、纸
- `LIGHT`：浅色面板

问题出在令牌之外。src/view 下大约 250 处硬编码十六进制，其中一部分是特效和美术（effects.ts 27、stone.ts 21、art.ts 19、shapes.ts 12），这些属于美术参数，可以留着。真正的 UI 颜色有这些重复：

| 用途 | 改前出现的值 | 改后令牌 |
|---|---|---|
| 成功绿（勾、进度条、绿按钮面） | 0x4cc35a ×8、0x5cc66a ×5 | `P.green` |
| 绿色阴影/按钮唇 | 0x2b7c36 ×4 | `P.greenDark` |
| 开关"开"、勋章 | 0x3c9a4a ×7 | `P.greenOn` |
| 浅底上的绿字 | 0x2b6a33 ×3、商店"已拥有"用 0x2b7c36 | `P.greenInk` |
| 浅底上的红字（弱点） | 0xb23a2a | `P.redInk` |
| 浅底描边棕 | 0x6e4c2f ×4（与 LIGHT.edge 重复） | `LIGHT.edge` |
| 战斗标签描边 | 0x3e3128 ×6 | `P.umber` |
| 锁定灰 | 0x8a7d6a ×6 | `P.locked` |

金色互相竞争：
- 界面：COLORS.gold 0xffcf3f（战斗横幅、光晕）和 P.brass 0xd9a441（菜单框）两种
- 特效：0xffe94a、0xffe25a、0xf5b800、0xffd34d（看广告按钮的徽标）、0xffd23a、0xfed501

特效里的金色是元素光，不算 UI。界面层建议定为"框用 brass，强调用 gold"两种，不再加第三种。standing 做法相同：一个高亮金 0xffd860，其余是框色。

## 3. 对比度（WCAG 比值）

| 组合 | 比值 | 结论 |
|---|---|---|
| ink 0x4a2c16 / paper | 9.9 | 好 |
| inkSoft 0x765637 / face | 5.9 | 好 |
| inkSoft / inset 0xe6dac2 | 4.8 | 够 |
| brassDark 0x8f5c1d / inset | 4.1 | 偏低，只适合大字 |
| P.red 0xe5484d / face | 3.5 | 不适合小字 → 弱点行改用 redInk（5.2） |
| greenInk 0x2b6a33 / face | 5.8 | 好 |
| 锁定灰 0x8a7d6a / face | 3.5 | 只用在图形上，不要用作字 |
| 白字 / 绿按钮 0x4cc35a | 2.3 | 靠深色描边撑住，描边不能再变细 |
| 提示文字 cream / 深底 0x14202c | 15 | 偏刺眼（主人说过 4.5–7 最舒服），见待定项 |

结论：**颜色本身大多合格，可读性的主要问题是字太小**，不是对比度。

## 4. 按钮、面板、进度条的一致性

- 按钮有三套：
  - 战斗 `Button`（ui.ts，平面圆角加描边）
  - 菜单 `PillButton`（kit/buttons.ts，带唇）
  - `adButton`（加播放徽标）

  菜单里的绿、紫、灰三色语义基本统一：绿是开始/继续/领取，紫是花晶石/看广告，灰是不可用。
  例外是战斗里的"强化"按钮：可用时紫，不可用时灰棕 0xa39480，白字对比只有 3.0，全靠描边。
- 进度条有四种画法，圆角和高度各不相同：
  - 任务条（白字压在条里）
  - 成就条
  - 胜利页伤害条
  - 墙血条（石槽）

  墙血条与成功绿同色。standing 在血条低血时分档变色，并把经验条换成边框色以免与血条混淆；我们的墙血条还没有分档。
- 面板（lightPanel、plate 标题牌、lightTile）统一得不错，不必动。

## 5. 强调色数量

主页一屏里同时有：
- 绿（开始）
- 紫（晶石价签）
- 黄铜/金（框、标题牌）
- 红（标题字、红点）
- 蓝（晶石）
- 灰棕（禁用）

一共六种，其中红点出现在五个页签里的四个，红色已经不再表示"这里有事"。建议红点只留给真正可以领取的地方（签到、任务），见待定项。

## 6. 字体

- 全局一套系统字体栈（system-ui / Segoe UI / PingFang SC / 微软雅黑），字重统一 800。ja、ko、th 另有本地字体。统一性没有问题。
- standing 给拉丁语系的大字（≥52）加了展示字体 Lilita One。我们的主要语言是中文，加展示字体只会让英文版好看，中文版不变；而且要多加载一个字体文件，首屏要等它。是否跟进由主人决定。
