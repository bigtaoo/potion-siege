# 《永远的蔚蓝星球》留存与商业化系统拆解（面向 CrazyGames 浏览器游戏的借鉴）

> 调研日期：2026-10-13。全部为公开网页信息，未登录、未下载。
> 标注说明：**[确]** 多个来源一致或来自官方商店页；**[单]** 仅单一攻略/玩家来源；**[疑]** 来源互相矛盾、可能过时或属于推断。
> 注意：该游戏版本迭代很快（2025-05 上线，2026-09 已到 3.0.x 版本、开了 S1 赛季），攻略中的数值随版本变化，仅作设计参考。

## 0. 结论速览

- 这是一款 **「局内轻（3 分钟一局、竖屏单手、随机召唤+2合1+三选一词条）＋局外重（抽卡、英雄等级/星级、装备、图腾、披风、国王等级）」** 的混合型产品，商业化以 **IAP（抽卡、月卡、礼包、战令）** 为主，靠巨量买量起量。
- 留存骨架：**体力（主线/合作）＋ 定时食堂体力 ＋ 每日次数类玩法（矿场、竞技场、合作券、锤子）＋ 开服 7 日/21 日活动 ＋ 按开服天数解锁新英雄 ＋ 周循环的商店/竞技币 ＋ 公会**。
- 玩家最爱：**每局阵容不重样的随机性、3 分钟短局、秒怪爽感、Q 萌画风**；最大流失点：**运气>实力、氪金压力、活动叠加付费、中后期难度墙（约 110 关后）、内容消耗快（"三天通关"）**。
- 对 CrazyGames 原型最值得先做的 5 项：①局外永久成长（金币→英雄等级/天赋）②章节/关卡制（20 波 = 1 关，逐关解锁+星级）③每日登录/每日任务＋每日挑战 ④激励广告的"多倍结算/免费宝箱"（克制使用）⑤图鉴/成就式长期目标。详见第 10 节。

- **国王等级**：由消耗体力获得经验，决定**所有模式的装备掉落等级**（国王 20 级掉到 40 级装备等）——即"消耗体力=账号成长"。（[17173](https://news.17173.com/content/11132025/080203648.shtml)、[17173](https://news.17173.com/content/12092025/225730938.shtml)）
- **单局 ↔ 永久成长的关系**：局内结果只决定通关与否和结算奖励；所有永久强度来自局外（英雄等级/星级、装备、图腾、披风、天赋/科技、城墙、皮肤加成）。攻略指出"攻击力"面板有误导性，图腾和城墙加成更关键。（[GameRes](https://www.gameres.com/forum/t/916439)）

## 10. 对 CrazyGames 浏览器游戏的适用性

### 10.1 CrazyGames 官方规则与指标（必须先读）

| 项目 | 内容 | 来源 |
|---|---|---|
| 上线流程 | **Basic Launch**：两周小流量测试，**广告关闭**、无分成，可不接 SDK；按指标对比平台基准决定是否进入 **Full Launch**（需完整接入 SDK，开启广告分成） | [Requirements intro](https://docs.crazygames.com/requirements/intro/)、[Basic launch metrics](https://docs.crazygames.com/resources/basic-launch-metrics/) |
| 三大指标 | **平均游玩时长**（单次会话）：成功作品常见 **10+ 分钟**；**次日留存**：强作品 **10–15%**；**转化率**（开始后玩满 1 分钟的比例）：头部 **80%+**，建议 <10 秒加载、包体 <20MB | [Basic launch metrics](https://docs.crazygames.com/resources/basic-launch-metrics/) |
| 官方提升留存建议 | 加入关卡/解锁/升级等进度；**每日钩子（登录奖励、每日任务）**；保存进度；修 bug | 同上 |
| 后台面板 | Developer Dashboard 提供玩家数、平均游玩时长、转化、留存、收入；高级分析推荐 ByteBrew | [Requirements intro](https://docs.crazygames.com/requirements/intro/) |
| 进入游戏 | 新用户应**直接进入玩法**，最多允许 1 次点击 | [Gameplay](https://docs.crazygames.com/requirements/gameplay/) |
| 质量指南 | 新手引导融入玩法、可跳过、少文字；清晰可达成的目标；避免重复无聊任务；按钮不得诱导点广告 | [Quality guidelines](https://docs.crazygames.com/requirements/quality/) |
| 存档 | SDK Data 模块：登录用户云存档跨设备同步，游客存 localStorage、登录后迁移；上限 1MB；提交时需勾选 Progress Save | [SDK Data](https://docs.crazygames.com/sdk/data/) |
| 中插广告 (midgame) | 只在自然断点（关卡切换、死亡后）；**不能挂在导航按钮**（主菜单/设置/商店）；SDK 自带频控，可随时请求 | [Ads requirements](https://docs.crazygames.com/requirements/ads/) |
| 激励广告 | 要"偶尔"出现；**不能设计成只有看广告才能过的关**；不能连播多条换一个奖励；**不能每次掉命都弹复活广告**；按钮不得出现在激烈战斗画面；跳过按钮与请求按钮同等大小；**须提供替代途径（如用游戏内金币购买）**；adError 时不给奖励；关卡之间"中插+重开"与"激励继续"二选一 | 同上 |
| 广告拦截 | 开了 AdBlock 也必须能正常玩，不能惩罚 | 同上 |
| 内购 | **仅邀请制**（Xsolla），Basic Launch 不可用——对小团队实际等同于"没有 IAP" | [Requirements intro](https://docs.crazygames.com/requirements/intro/) |

> ⚠️ 对现有原型的直接影响：你已有的"激励广告复活"需要**限次**（如每局 1 次），并提供**非广告替代**（例如消耗局外货币/复活币复活），否则违反"每次掉命都弹广告"的条款。Basic Launch 期间广告关闭，复活按钮必须隐藏或改为非广告方式，不能出现点了没反应的按钮。
>
> 核对注：原文是 "rewarded ad buttons shouldn't be left without effect"。药水围城的 `CrazyGamesPlatform` 在 Basic Launch 下点激励按钮会直接发奖，满足这条；真正要改的是"每次失败都弹复活"和"没有非广告替代"。

### 10.2 逐系统取舍

| 系统（蔚蓝星球） | 取舍 | 具体做法（CrazyGames 版本） |
|---|---|---|
| 3 分钟短局、随机召唤+合成+三选一词条 | **保留**（已有） | 你的 20 波 run 偏长，可考虑每 5 波一个 Boss 节点，让"松-紧-松"节奏和首个 Boss 出现在约 90–120 秒 |
| 召唤价格 S 曲线、格子随召唤扩张 | **保留/借鉴** | 低成本的数值手段，让中段（Boss 前）资源最紧张，制造决策压力 |
| 精英/Boss 宝箱老虎机 | **借鉴** | 局内 Boss 掉"转盘宝箱"（银币或英雄技能），纯随机爽点，无需广告 |
| 主线关卡（每关 10 波、三星宝箱、首通倍速） | **改造** | 做成"章节/关卡"：关卡 1→N，每关有星级目标与首通奖励；首通后解锁 1.5x/2x 速度；比"只有 best wave"更有下一个目标 |
| 体力 | **舍弃** | 浏览器单次会话玩家，体力只会砍游玩时长（平台核心指标）。若要制造"明天再来"，用"每日首 3 局双倍奖励"替代体力 |
| 定时食堂体力（6/12/18/21 点） | **改造** | 改为"每日首次登录宝箱"+"离线累积金币（上限 8 小时）"，不依赖固定钟点 |
| 局外英雄等级/星级（碎片） | **改造（核心）** | 去掉抽卡，用 run 结算金币直接升级 5 种英雄的基础属性；英雄"解锁"由关卡进度给，不随机 |
| 国王天赋/科技树、城墙升级 | **保留（简化）** | 一棵 10–20 节点的天赋树（城墙血量、初始银币、召唤折扣、词条刷新次数），金币购买 |
| 装备、图腾、披风、宠物、洗练 | **舍弃** | 系统过多、货币过多；原型阶段只留"一种局外货币 + 一棵树 + 英雄等级" |
| 抽卡 / 招募池等级 / 星愿转盘 | **舍弃**（或改为广告免费宝箱） | 若需随机惊喜：每日 1 个免费宝箱 + 可选看 1 次激励广告再开 1 个（有冷却，且可用金币购买替代） |
| 月卡、战令、礼包、皮肤付费 | **舍弃/改造** | 战令改为免费"成就/赛季任务"轨道，进度靠游玩累积；皮肤改为成就解锁 |
| 签到 / 7 天乐 | **保留（简化）** | 7 日登录奖励（第 7 天给新英雄或稀有皮肤）。注意多数玩家不会回来，奖励要在第 1 天就有可见价值 |
| 每日任务 | **保留** | 3 条每日任务（打到第 X 波、合成 X 次、选 X 次某技能），完成给金币 |
| 每日挑战/特殊规则局 | **新增（替代合作/赛季）** | 固定种子 + 特殊词条（"只能召唤法师"），全玩家同题，可配排行榜 |
| 竞技场 / 合作 / 公会 | **舍弃**（原型期） | 多人与公会成本高；CrazyGames 支持多人，但原型阶段不做 |
| 排行榜 / 全服首通奖励 | **改造** | 每日挑战排行榜（需 CrazyGames 账号或本地）；"全服首通"可做成全局计数器激励，后期再说 |
| 怪物图鉴（首次遭遇奖励） | **保留** | 成本低：首次遇到/击杀某怪、首次合成 4 星某英雄 → 给金币，同时是长期收集目标 |
| 开服天数解锁新英雄 | **舍弃** | 换成"关卡进度解锁" |
| 挂机/离线收益 | **可选** | 有助回流，但对"很多人不回来"的平台价值有限；排在后面 |
| 激励广告（双倍结算、免费宝箱、复活、刷新词条） | **保留（克制）** | 见下表 |
| 存档 | **必须** | 用 CrazyGames SDK Data 模块（<1MB，游客 localStorage 自动迁移） |

### 10.3 建议的激励广告位（全部可选，且需有金币替代）

| 位置 | 规则 | 合规要点 |
|---|---|---|
| 结算页"奖励 ×2" | 每局 1 次，失败也可 | 放在结算页而非战斗中；广告失败不给奖励 |
| 复活 | 每局最多 1 次；也可用"复活币"（每日任务/成就产出） | 不能每次失败都弹；不与"中插+重开"同时出现 |
| 每日免费宝箱的第二次开启 | 冷却 4–6 小时 | 不能连播；明确标注视频图标 |
| 词条刷新（三选一重抽） | 每局 1 次免费 + 1 次广告；也可用局内银币刷新 | 按钮不能出现在激烈战斗画面——放在升级弹窗（游戏暂停时）可接受性需自行判断，保守做法是只在波次之间 |
| 中插（midgame） | 关卡结束/失败后、点击"再来一局"时请求，频控交给 SDK | 不挂在主菜单/商店按钮 |

### 10.4 原型优先级 Top 5

已有：20 波 run、5 种英雄×4 星召唤合成、升级肉鸽三选一、广告复活、最高波次存档。

| 排名 | 系统 | 理由 | 对应指标 |
|---|---|---|---|
| **1** | **局外永久成长：单一货币（金币）+ 英雄等级 + 小天赋树（城墙/初始银币/召唤折扣）** | 蔚蓝星球的全部留存都建立在"局外变强"；失败也有收获，直接拉长单次游玩与次日回访；用 SDK Data 存档 | 游玩时长、次留 |
| **2** | **关卡/章节结构（取代单纯 best wave）** | 每关 10–20 波、每 5 波 Boss；关卡解锁新英雄/新敌人/倍速；三星目标；给玩家永远清晰的"下一个目标"（官方质量指南要求） | 游玩时长、转化 |
| **3** | **每日钩子：7 日登录奖励 + 3 条每日任务 + 每日首 3 局双倍** | CrazyGames 官方明确建议"登录奖励、每日任务"提升次留；成本低 | 次留 |
