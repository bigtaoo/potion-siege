# 新手引导方案：前三关带玩家走完所有功能

2026-11-02 · 第 7 节的决定已定，法术数值待平衡脚本

## 0. 结论速览

- **问题**：第一局教学之后引导就断了。首胜回到主页，手指点完药剂升级就没有下文：没有手指回到「出战」，工坊、每日任务、图鉴、商店、挑战都要靠玩家自己找。
- **数据**（Playgama + 网页，去掉自己和 QA，约 8 个真实玩家）：
  - 回到主页的玩家会自己点开工坊、图鉴、商店，也会花钻石。说明他们愿意探索，只是没人带路。
  - 但他们进第二关后 6–30 秒就退出，城墙始终 100%，**第二关里强化一次都没用过**（upgrades 0）。
  - 第一局要打 220–250 秒，偏长。
  - 结论：只讲主页不够，第二、三关的局内也要有引导。
- **方案**：把「第一局教学」扩展成贯穿前三关的分章引导：
  - **每局一章**：局内教一个新操作，回主页教两三个功能，最后一步永远是手指回到「开始战斗」。
  - **之后按需出现**：第 4 关以后的功能（新药剂、章节宝箱、星级宝箱、无尽、困难）都在第一次可用时用同一套机制点一次。
- **实测补充（11-02）**：第一局教学后，「有事可做却没有提示」累计 98 秒；强化后选技能 5 秒没有手；指挥官 6 次施法全是自动的。原因都是提示要等闲置 3–5 秒。前三局改成「能做就提示」（0.6 秒），见第 2 节和第 3 节的逐秒流程。
- **原则**：
  - 前一分钟不挡战斗（CrazyGames 转化率的教训）。
  - 一次只指一样东西。
  - 每步都有「跳过」。
  - 从不替玩家操作。

### 数据里能看到的路径

- **a.** 赢第 1 关 → 下一关进第 2 关 → 6 秒内放弃回主页。这是 11-02 已经改掉的「首胜回主页」。
- **b.** 回主页 → 礼包 → 手指升级 → 自己逛工坊 / 图鉴 / 商店 → 进第 2 关 → 10–30 秒退出，没用过强化。
- **c.** 第 1 关连输 3–4 次（城墙被破）。现在只有失败提示，没有局内补救。
- **d.** 下一关一路 1 → 2 → 3，第 3 关 51 秒退出。从没见过主页。

### 实测：第一局的提示时间线（11-02）

做法：本地新存档，页面里装一个探针，扮演「只照提示做、看到提示 1 秒后才动手」的新玩家，按 1/30 秒逐帧推进整局，记下每一刻「能做什么」和「屏幕上在提示什么」。这一局 233 秒赢下。

| 战斗时间 | 能做的事 | 屏幕上的提示 | 问题 |
|---|---|---|---|
| 合成之后 0–7 秒 | 无（召唤灰着，等第 1 瓶免费药剂） | 无 | 7 秒空等，不知道在等什么 |
| 7.4 秒 | 免费召唤 | 教学「再召唤一瓶」+ 手 | 正常 |
| 7.7–14.6 秒 | 无（等第 2 瓶） | 无 | 又空等 7 秒 |
| 14.6 秒 | 免费召唤 | 教学 + 手 | 正常 |
| 16.1–19.1 秒 | **付费召唤、合成** | **无** | 你说的「能召唤了没提示」：两瓶免费的发完，教学的「强化」步在等 100 金币，`showing()` 返回 null，战斗全速；局内闲置手在教学期间是关的 |
| 19.1 秒 | 同上 | 只有召唤按钮鼓一下（`idlePulse`，3 秒后），没有手 | 提示太弱 |
| 22.2 秒 | 强化 → 选技能 | 教学气泡；**卡上没有手**（教学的 pick 步把手藏了） | |
| 22.2–27.2 秒 | 选技能 | 无手 | 你说的「等很久才出手」：`CardNudge` 要 5 秒没碰屏幕才出，按下或拖动一下就重新计时 |
| 教学后 22–233 秒 | — | — | 见下 |

教学结束后（约 210 秒）：

- **有事可做却没有任何提示，共 98 秒，分成 34 段。** 规律很固定：
  - 钱够召唤：3 秒后召唤按钮鼓一下，4 秒后才出手（`IDLE_SUMMON_AFTER`）。
  - 出现可合成的一对：4 秒后才出手。
  - 每做完一次操作，计时从零开始，所以每一步都要再等 3–4 秒。
- **强化**：110.7 秒起就够钱，前后 34 秒可强化，但手的优先级是「合成 > 强化 > 召唤」，一直在合成的人看不到强化。
- **第 2、3 次选技能**（210、216 秒）：同样 5 秒后才出手。
- **指挥官施法**：整局 6 次，全部是满了 15 秒后自己放的。指挥官的手给棋盘的手让位（`handOff.board`），而棋盘的手几乎一直在，所以新手基本看不到它。
- 真正没事可做（等钱）的时间是 74 秒，这部分正常。

结论：第一局不缺提示的种类，缺的是**时机**。几乎每个提示都要先闲置 3–5 秒才出现，而新手在这 3–5 秒里正是不知道该做什么。

## 2. 总体结构

```
第1局  局内：召唤 → 合成 → 强化 → 选技能 → 【新】施法
       结算：继续（已改）
主页①  礼包 → 药剂升级（可连升） → 【新】回出战 → 开始第2关
第2局  局内：【新】强化提醒（有钱就指） → 【新】结算讲星级
主页②  签到 → 【新】每日任务领奖 → 【新】工坊买一级 → 回出战 → 第3关
第3局  局内：飞行兵卡（已有）+【新】选技能前讲推荐
主页③  【新】图鉴领成就 → 【新】商店免费宝箱 → 【新】每日挑战按钮介绍 → 开始第4关
之后   按需一次：新药剂换阵容 / 星级宝箱 / 章节宝箱 / 加速按钮 / 无尽 / 困难
```

- 每章结束时手指落在「开始战斗」，玩家点了就进下一关。
- 前三关的胜利结算都只给「继续」回主页（第 7 节第 1 点，已定），因为主页②③要讲的东西正是留住玩家的系统。
- 输了也走同一套：主页的引导照常进行。失败提示里能做的那一项（通常是升级药剂）会和当章的步骤合并，不重复指。

### 局内提示规则（前三局，`runs < 3`）

实测的问题是「等闲置才提示」。前三局改成「能做就提示」，第 4 局起回到现在的闲置规则。

1. **什么时候出手**：某件事刚变成可做时，0.6 秒后出手和按钮发光，不等闲置。
   - 唯一的延迟：玩家 1 秒内刚按过屏幕，就等到松手满 1 秒。这样正在拖药剂的人不会被手挡住。
   - 玩家做了被指的事，手立刻收起；下一件可做的事照样 0.6 秒后出。
2. **一次只有一只手，按这个顺序指**：

   | 顺序 | 情况 | 指向 | 为什么排这里 |
   |---|---|---|---|
   | 1 | 技能卡开着 | 推荐卡，卡片展开动画结束（约 0.5 秒）就出 | 战斗是停的，别的都做不了 |
   | 2 | 指挥官刚充满 | 指挥官徽章，最多指 4 秒 | 免费、效果大，4 秒后让给下一项；满 15 秒自动施法照旧 |
   | 3 | 强化够钱 | 强化按钮 | 强化给新技能，是局内成长最大的一步；现在排在合成后面，新手几乎看不到 |
   | 4 | 有可合成的一对 | 拖动的手 | |
   | 5 | 能召唤且有空格 | 召唤按钮 | |

   顺序 2 的指挥官手不再让位给棋盘的手（`handOff.board` 只在顺序 4 的手正在拖的那一下生效）。
3. **按钮自己也提示**：召唤、强化够钱的那一刻按钮亮起并鼓一下（不需要手）。这一条所有局都保留，是给老玩家的轻提示。
4. **等钱的时候说清楚在等什么**：召唤和强化按钮上已有价格，前三局在按钮上加一圈进度（金币 / 价格），满了就亮。
5. **玩家不照做**：手一直在，不加码、不减速（只有第 1 局的教学步才减速）。

## 3. 每一步的细节

每一步由四项组成：**出现条件**、**指向**、**一句话**（巫师头像 + 气泡，复用第一局教学的「新手教学 n/m · 跳过」框）、**完成条件**。

### 第 1 局（局内）：逐秒流程

时间是战斗时间（教学减速时按实际经过的秒数估）。「教学」指现有的「新手教学 n/m」气泡 + 手 + 0.2× 慢动作；「提示」指上面的局内提示规则（不减速）。

| 时刻 | 屏幕上发生什么 | 玩家要做的 | 提示 | 和现在比 |
|---|---|---|---|---|
| 0 秒 | 进局，「大军来袭」，敌群往下走 | — | 召唤按钮已经发光 | 现在要等 2 秒 |
| 0.6 秒 | | 召唤 | 教学 1/5「点击召唤，召来一瓶药剂」+ 手；2 秒后减速 | 手提前出现 |
| 召唤后 | 第 1 瓶上场，金币 40 | 再召唤 | 教学「再召唤一瓶」（现有 `more`） | 不变 |
| 出现一对 | 两瓶同样的药剂 | 合成 | 教学 2/5「把它们拖到一起」+ 拖动的手 | 不变 |
| 合成后 0–3 秒 | 等第 1 瓶免费药剂 | — | 召唤按钮上一圈倒计时 +「免费」字样；`GIFT_EVERY` 从 7 秒改成 3 秒 | 现在空等 7 秒 |
| +3 秒 | 免费药剂到 | 召唤 | 教学 3/5「再召唤一瓶」+ 手 | |
| +6 秒 | 第 2 瓶免费药剂 | 召唤 | 同上 | 现在 +14 秒 |
| 免费发完、强化还不够钱 | 常常又能召唤、能合成 | 合成或召唤 | **教学继续指**：有一对就指合成，否则能召唤就指召唤（`showing()` 在 upgrade 步不再返回 null）；强化按钮上的进度圈在涨 | 现在这里 3 秒无提示 |
| 金币到 100 | | 强化 | 教学 3/5「金币够了，点强化」+ 手 | 不变 |
| 强化后 | 技能卡弹出，战斗暂停 | 选卡 | 教学 4/5「选一个技能，推荐的最适合现在」；**手在卡片展开后立刻落在推荐卡上** | 现在没有手，5 秒后才由 `CardNudge` 出 |
| 选完 | 战斗继续 | — | 教学气泡收起，进入局内提示规则 | |
| 指挥官第一次充满（约 40–60 秒） | 指挥官发光，战场上出现一个虚线圈落在敌群最密处 | 拖动施法 | 教学 5/5「把炸瓶拖到敌群里」+ 手从指挥官拖到虚线圈，0.2× 慢动作（见第 3.5 节新法术） | 新增；现在 6 次全是自动施法 |
| 之后 | 正常战斗 | 召唤 / 合成 / 强化 / 选卡 / 施法 | 局内提示规则，0.6 秒出手 | 现在 3–5 秒 |
| 第 5 波首领 | 蒸汽坦克出场 | — | 敌人卡（复用新敌人卡）「很硬，合成高星药剂来打」，3 秒自动收起，不停战斗 | 新增 `bossCard` |
| 胜利 | 结算 | 继续 | 「继续」按钮发光 + 手（已改：首胜回主页） | |

要点：

- 教学从 4 步变 5 步（加 `cast`）。施法不放在开头，因为指挥官要靠击杀充能，放在开头会让前一分钟变长。
- 强化步「等钱」的这段，以前是空白，现在让玩家把刚学的召唤、合成再做几次，正好是巩固。
- 卡片的手和教学气泡同时出现，不再靠 `CardNudge` 的 5 秒闲置。`CardNudge` 本身也改：前三局卡片展开后立刻出手，按下时隐藏，松手 1 秒后再出。
- 第 1 关保持约 4 分钟，不缩短（第 7 节第 6 点）。

### 主页①（第 1 局后）

| id | 出现条件 | 指向 | 一句话 | 完成条件 |
|---|---|---|---|---|
| `gift` | 礼包弹窗打开 | 「领取」按钮 | 「新手礼包，每天来领一份」 | 领取 |
| `upgrade` | 有钻石够升级 | 药剂标签 → 推荐药剂的升级按钮 | 「用钻石升级药剂，伤害更高」 | 买一次 |
| `upgradeMore` | 买完后还够再升 | 同一按钮，不再出气泡 | — | 再买一次，或钻石不够，最多连指 3 次 |

- 隐私同意框照旧最先出现（法律要求），引导排在它后面。

- `toBattle` 就是这次缺的那个「然后」。

主页①逐步（主页每一章都用同样的时机）：

| 时刻 | 屏幕 | 手 / 气泡 |
|---|---|---|
| 结算点「继续」 | 主页滑入 | 无 |
| +0.5 秒 | 礼包弹窗 | 0.5 秒后手在「领取」上 |
| 领取后 | 弹窗关 | 0.5 秒后气泡 + 手在药剂标签 |
| 打开药剂页 | | 立刻手在推荐药剂的「升级」上（推荐标签和手是同一瓶） |

- 玩家 8 秒没动：只让手和气泡轻轻弹一下，不加字、不弹窗。

### 第 2 局（局内）：逐秒流程

没有教学减速，全程是局内提示规则，只加两句一次性的话（气泡在屏幕上方，不挡棋盘，3 秒或玩家照做后收起）。

| 时刻 | 发生什么 | 提示 |
|---|---|---|
| 0 秒 | 进局，金币 50 | 召唤按钮发光，0.6 秒出手 |
| 0–20 秒 | 召唤、合成 | 每件可做的事 0.6 秒出手 |
| 第一次够钱强化 | | 强化按钮亮 + 手；气泡 `upgrade2`「强化一次，换一个新技能」 |
| 技能卡 | 战斗暂停 | 推荐卡 + 手立刻出 |
| 指挥官充满 | | 手指 4 秒；如果第 1 局一次都没自己施法，再配一句「按住指挥官拖到敌群里」 |
| 胜利结算 | 星级 | 星星下一行字 `stars`「城墙剩 50% 得 2 星、80% 得 3 星，星星能换宝箱」 |
| 失败结算 | | 现有失败提示，第一条按钮发光 |

- 数据里第 2 局强化数为 0，这里由规则表的顺序 3 解决：强化够钱就排在合成前面指。

### 顺序核对（11-02，用第 1 局刚打完的新存档）

第 1 局赢下回到主页时，存档是这样的：

| 项目 | 状态 | 数额 |
|---|---|---|
| 钻石 | 192（礼包另算） | |
| 药剂升一级 | 60 | 够升 3 次 |
| 工坊 | 城墙 60 / 起始金币 50 / 钻石加成 80 | |
| 每日任务 | 第 1 局后已完成可领的一项；「打 3 场」1/3；「合成 25 次」14/25 | 130 |
| 成就 | 通关、击败敌人等第一局后能领的第一档可领 | 30 + 80 + 80 |
| 商店免费宝箱 | 今天可领 | 150 |
| 签到 | 第 1 天可领（按钮在，第 2 局后才自动弹） | 130 |

也就是说，第 1 局之后所有东西**已经都能领**，约 600 钻石摆在那里。排顺序用了三条原则：

1. **先领后花**：每次回主页先领奖励，再去花，花的那一步一定买得起。
2. **最核心的先教**：药剂升级是每局之后都要做的事，放在主页①；签到、任务是「明天再来」的理由，放在主页②；图鉴、商店、挑战是长期的东西，放在主页③。
3. **每次回家最多 4 步、约 20 秒**：主页①只有 3 步，尽快回到第 2 关（数据里第 2 关是流失最多的地方）。

按这三条，第 3 节原来的顺序只需要一处改动：主页②把「每日任务」挪到「工坊」前面（先领 130 再花 60）。最终顺序：

```
主页①  礼包 → 药剂升级（最多 3 次）→ 开始战斗
主页②  签到 → 每日任务领奖 → 工坊买城墙 → 开始战斗
主页③  图鉴领成就 → 商店免费宝箱 → 每日挑战按钮 → 开始战斗
```

没有把工坊提前到主页①：主页①的钻石够升 3 次药剂，再加工坊会变成 5 步，而且两种升级同时出现，新手分不清区别。

### 新法术：玩家自己选落点

你说现在的法术鸡肋，代码里看确实如此：

- **炸瓶**：伤害 = 棋盘每秒总伤害 × 0.6 秒，自动扔向敌群最密处。也就是说一次施法只等于药剂们多打 0.6 秒。
- **灌注**：药剂攻速 +30%，持续 2 秒，折合也只有约 0.6 秒的伤害。
- 两个轮流放，落点全自动，玩家点不点结果差不多，满 15 秒还会自己放。实测 6 次全是自动放的，玩家不会觉得这是自己的技能。

**新设计：拖到哪里，落到哪里。**

1. **操作**
   - 指挥官充满后，按住指挥官徽章拖到路上，手指下面跟着一个范围圈，圈里会被打到的敌人描白边；松手就在那里施放。
   - 拖回徽章或拖出路面，取消，充能保留。
   - 只点一下不拖：照旧扔向敌群最密处，保留「一点就放」给不想瞄准的人。
   - 电脑上：点徽章后再点路面，或者直接拖。
   - 满 15 秒自动施放保留，免得闲置的新手浪费充能。
2. **三个法术轮流**，徽章上显示下一个是什么，玩家可以提前想好放哪里：

   | 法术 | 范围 | 效果 | 什么时候用 |
   |---|---|---|---|
   | 爆裂瓶 | 半径 190 | 伤害 = 棋盘每秒总伤害 × 2 秒，并把敌人推后半格 | 敌群最密处 |
   | 冰霜瓶 | 半径 240 | 冻住 2.5 秒（首领改为减速 50%） | 一波快冲到城墙时 |
   | 酸液池 | 半径 160，留在地上 5 秒 | 走进去的敌人每秒受到棋盘每秒伤害的 25%，并减速 30% | 敌人必经的路口 |

   数值是起点，最后用 `npm run lazy`、`npm run bosses`、`npm run endless` 调到「放得好的一次 ≈ 救下 5–10% 城墙」。
3. **规则层**
   - 施法命令加落点：`{type: 'cast', x, y}`（定点数坐标）。没有落点的旧命令 = 敌群最密处，旧回放照样能放。
   - 机器人（autoplay、平衡脚本）用最密处，平衡测量不受影响。
   - 埋点：`cast` 事件加 `how: drag | tap | auto` 和命中数，可以看出玩家到底会不会瞄。
4. **教学**：第 1 局的第 5 步改成教拖动：慢动作下，手从指挥官拖到敌群上的虚线圈；松在路上任何地方都算完成。
5. **每日任务**：现有任务里没有「施法」（skill 是「选择 6 个技能」），也没有施法成就；新增 cast 任务会改变每天抽到的任务，先不做，等主人决定。

这一项改动比引导本身大（规则、画面、平衡、回放都要动），建议单独做一个分支，先于引导的第 5 步完成。引导的其余部分不依赖它。

## 4. 规则

1. **一次一步。** 引导在指的时候，其他红点全部暂停。这把现在的 `navDots(pointing)` 推广到所有步骤。
2. **软引导。** 不锁住别的按钮。
   - 玩家点了别处，这一步算「跳过」，进下一步。
   - 气泡上永远有「跳过」，点了跳过本章剩下的步骤，只留 `toBattle`。
3. **不替玩家做。** 和第一局教学一样，只指不点。
4. **局内不挡。**
   - 只有第 1 局的 5 个教学步用慢动作（`cast` 是新加的第 5 步）。
   - 第 2、3 局的步骤只发光、出手、出一行字，不减速、不暂停。
5. **一章最多 4 步。** 主页每次停留最多约 20–30 秒，然后一定回到「开始战斗」。
6. **钱要够。** 每步出现前检查条件（买得起、可领）。不满足就跳过这一步，不要指着一个点了没用的按钮。
7. **老存档不补课。**
   - `runs > 0` 的老存档：前三章全部算完成。
   - 「之后」那些一次性步骤照常触发。

## 5. 技术方案

- **规则层 `src/sim/guide.ts`（新文件，纯规则）**
  - 步骤表：`id`、`chapter`、`when(save, ctx)`、`done(event)`。
  - `nextStep(save, place)` 返回当前该指的步骤，`place` 是 home 或 battle。
  - 单测放在 `guide.test.ts`。
- **存档 `MetaSave.guide: string[]`**
  - 记录已完成或跳过的步骤 id。
  - `parseMeta` 回填：没有这个字段且 `runs > 0` 的存档写入前三章全部 id。
  - `upgradeHint` 迁移成 `upgrade` 这个 id，之后删除旧字段。
- **主页**
  - `pointer.ts` 和 `nav.ts` 现在只认药剂标签，改成「按目标 id 求位置」：标签、顶栏按钮、面板按钮、开始战斗。
  - 气泡复用 `Tutorial.ts` 里的教学框。
  - 进主页的弹窗顺序由引导统一排队：隐私 → 礼包 / 签到 → 引导步骤。不再让弹窗把手指挤掉。
- **局内**
  - `src/sim/tutorial.ts`：
    - upgrade 步等钱时 `showing()` 改成：有一对 → `merge`，能召唤 → `again`（付费也算），都不能 → null。
    - 加第 5 步 `cast`：指挥官第一次充满时出，`pace()` 照样减速。
  - `GIFT_EVERY` 7 → 3 秒，召唤按钮在等免费药剂时画倒计时圈；改完用 `npm run lazy` 和 `npm run gaps` 看第 1 关有没有变。
  - 新模块 `src/view/hudPointer.ts`（从 `Hud.ts` 拆出来，Hud 已接近上限）：前三局的「能做就提示」规则和第 2 节的优先顺序；第 4 局起退回现在的闲置计时。教学期间也开着，只是教学步优先。
  - `cmdHints.ts`：`handOff.board` 只在拖动的手正在动时生效；新手期指挥官手排在强化前。
  - `cardNudge.ts`：`CARD_NUDGE.after` 前三局改成 0.5 秒（卡片展开后），按下时隐藏、松手 1 秒后回来；教学 pick 步不再藏手。
  - `upgrade2`、`stars`、`pickTip`、`bossCard` 是一次性气泡或一行字，记在 `MetaSave.guide`。
  - 验证：保留这次的探针做法（新存档、照提示做的假玩家、逐帧推进），写成 `npm run onboard`，输出「有事可做却无提示」的总秒数和最长一段。目标：前三局每局 < 10 秒、最长一段 < 1.5 秒。
  - 首次结果（2026-11-02，假玩家 0.5 秒反应，前三局都赢）：无提示 14.8 / 24.9 / 23.7 秒，最长一段 1.1 / 1.0 / 1.0 秒。最长一段达标；总数没达标，几乎全是每步之后 `EARLY.rest` 1 秒 + `EARLY.show` 0.6 秒的小空档（每局 19–32 段，约一半紧接玩家的上一步）。按「先保持现有节奏」不改。
- **埋点**
  - 新事件 `guide_step {id, chapter, shownT, waitS, result: done|skipped|other, run}`。
  - Playgama 的 `bridgeSink` 也映射这个事件。
  - `npm run report` 加一张「引导漏斗」表：每步出现数、完成率、平均等待。
- **文件大小**：每个新模块按职责拆，单个文件不超过 500 行，测试同样。

## 6. 怎么判断有没有用

| 指标 | 现在 | 目标 |
|---|---|---|
| 第 1 局后开始第 2 关的比例 | 大部分会开始，但很快退出 | 不变或更高 |
| 第 2 关前 30 秒退出率 | 几乎全部 | 明显下降 |
| 第 2 关用过强化的比例 | 0 | > 70% |
| 打到第 4 关的比例 | 约 1/8 | 翻倍 |
| 每步完成率（`guide_step`） | — | 每步 > 70%，低于 50% 的步骤删掉或改写 |

Playgama 自然流量接近 0，靠线上样本判断不了。先以自己从新存档完整玩一遍为主，等有分发量或开始测试招募后再看数据。
